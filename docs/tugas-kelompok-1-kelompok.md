## 📌 Komitmen Kerja Kelompok
1. Seluruh anggota wajib berkontribusi aktif melalui pembuatan commit dan review Pull Request.
2. Setiap kendala teknis atau koordinasi dicatat secara transparan pada GitHub Issues.
3. Seluruh pesan commit mengikuti konvensi baku: `<tipe>(<bagian>): <ringkasan perubahan>`.
4. Repositori dijaga tetap bersih dari file rahasia (`.env`), token, atau folder dependensi (`node_modules/`, `build/`).
